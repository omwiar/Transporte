# Buscador de Flota

Prototipo de una app para intermediación de transporte: se ingresa el peso y las medidas de la carga de un cliente y muestra qué vehículos de los proveedores la pueden llevar, ordenados por mejor ajuste.

Todos los datos (proveedores, contactos, placas, tarifas) son de ejemplo. Las capacidades y medidas de los vehículos son aproximadas.

## Uso

Abrir `index.html` en un navegador. No requiere instalación ni servidor.
